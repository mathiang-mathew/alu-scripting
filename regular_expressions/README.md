# Regular Expressions

This project contains Ruby scripts that use regular expressions built for the Oniguruma library.

## Tasks

### 0. Simply matching School
`0-simply_match_school.rb` accepts one argument and prints every occurrence of the word `School` found in it.

### 1. Repetition Token #0
`1-repetition_token_0.rb` accepts one argument and prints it if it matches `hb`, followed by two to five `t` characters, followed by `n`.

### 2. Repetition Token #1
`2-repetition_token_1.rb` accepts one argument and prints it if it matches `h`, followed by zero or one `b`, followed by `tn`.
